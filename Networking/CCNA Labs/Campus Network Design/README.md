# Campus Network Design (Cisco Packet Tracer)

A campus-level network design built in Cisco Packet Tracer, following the hierarchical three-layer model:

- **Core layer:** three Cisco 2911 routers interconnected with GigabitEthernet point-to-point links
- **Distribution layer:** two Cisco 3650-24PS multilayer switches
- **Access layer:** seven Cisco 2950-24 switches grouped into seven user VLANs (VLAN 10-70), two PCs per VLAN (14 PCs total)
- **Server:** a central server (Server0, 10.0.0.2) attached to the core
