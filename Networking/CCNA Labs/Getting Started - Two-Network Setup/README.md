# Getting Started with Cisco Packet Tracer: Two-Network Setup

**Status:** Practice lab (October 2026)

**Built with:** Cisco Packet Tracer

My first hands-on Packet Tracer lab: two separate IP networks built from scratch, with a router connecting them so devices on one network can reach devices on the other.

## What it covers

- Building a small topology with end devices, switches and a router
- Assigning IP addresses, subnet masks and default gateways
- Checking connectivity with ping, within each network and between the two networks

## Skills practiced

IPv4 addressing, subnet masks, default gateways, basic cabling, ICMP ping testing.
